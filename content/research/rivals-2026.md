### Plans and prices

`[https://ahrefs.com/pricing, checked 4 Oct 2026]` — annual figures read off the page's own "Pay annually, save up to 17%" toggle. Starter detail: `[https://help.ahrefs.com/en/articles/9419051-about-ahrefs-starter-plan, checked 4 Oct 2026]`

### Credits / limits model

- "1 credit is consumed whenever you open a report, apply filters, or request additional data" — applies to all tools **except Site Audit and Rank Tracker**. `[https://help.ahrefs.com/en/articles/6061657-ahrefs-usage-based-pricing-for-credit-based-plans, checked 4 Oct 2026]`
- **The big structural fact:** Starter = 200 credits/mo, Lite = **1,000 credits per user**, and **Standard and above are "unlimited credits per user"** ("unlimited fair usage for every active user"). `[https://ahrefs.com/pricing + https://help.ahrefs.com/en/articles/6117209-what-s-the-difference-between-all-ahrefs-subscription-plans, checked 4 Oct 2026]`
- **Verifying site ownership earns +500 credits/mo** (spendable only on URLs inside verified projects) and **+5,000 crawl credits per verified project**. Verified projects are **unlimited** on every plan. `[https://ahrefs.com/pricing + https://help.ahrefs.com/en/articles/14333008-about-rows-export-rows-and-user-limits, checked 4 Oct 2026]`
- **Pay-as-you-go top-ups:** $50 per 500 credits billed monthly, or $300/yr prepaid for +500 credits each month. Disabled by default. `[https://help.ahrefs.com/en/articles/6061657-..., checked 4 Oct 2026]`
- **Expiry:** report credits, export rows, crawl credits and API units "last for three billing months" from accrual; pre-paid limits are spent first. `[same, checked 4 Oct 2026]`
- **Rows:** max rows per report 2,500 / 30,000 / 75,000 / 150,000 (Lite→Enterprise). Export rows per month 500,000 / 1.5M / 4M / from 10M. `[https://ahrefs.com/pricing, checked 4 Oct 2026]`
- **Site Audit caps:** max pages per project 25,000 / 50,000 / 250,000 / 5M. `[same]`
- **Seat nuance:** older credit-based plans charged by user activity band — Inactive (0–5 credits) $0, Casual (6–100) $20/mo, Power $40–$80/mo depending on plan. Inactive users (Site Audit/Rank Tracker only) are free to add. `[https://help.ahrefs.com/en/articles/6061657-... + .../14333008-..., checked 4 Oct 2026]`

### API

**API and MCP access is listed on every paid plan including Lite ($129).** Shared API units across v3, MCP and Ahrefs Connect: 200,000 / 800,000 / 2M / 4M per month; max rows per request 100 / 250 / 500 / unlimited. Enterprise adds uncapped API and custom endpoints. `[https://ahrefs.com/pricing, checked 4 Oct 2026]`

### Ahrefs Webmaster Tools (free tier)

Free, for **sites you verify ownership of**: Site Explorer, Site Audit ("170+ technical & on-page SEO issues") and Web Analytics. Limits: **5,000 crawl credits per month per project**, **1,000 backlinks and keywords viewable at once**, up to **1 million Web Analytics events per project per month**, **1 free AI Content Helper document per month**, **unlimited verified websites**. It does **not** cover competitor or unverified domains, and does not include Keywords Explorer or Rank Tracker. `[https://ahrefs.com/webmaster-tools, checked 4 Oct 2026]`

### What changed by 2026

- **Credits are gone above Lite.** Standard/Advanced/Enterprise are now "unlimited credits per user"; Ahrefs' own help doc tells credit-based legacy customers to move to the newer unlimited plans. `[https://help.ahrefs.com/en/articles/6061657-..., checked 4 Oct 2026]`
- **API/MCP opened downward.** API *and an MCP server* are on every paid tier from $129, with unit allowances rather than a plan gate. `[https://ahrefs.com/pricing, checked 4 Oct 2026]`
- **AI-visibility is now a priced line item**, not a feature. Brand Radar AI "from $199/mo"; custom prompt packages $50 (+2,500 checks) / $100 (+7,000) / $250 (+25,000), overages $0.020 / $0.015 / $0.010 per check. Plans themselves include only 5 / 10 / 20 tracked AI prompts. `[same]`
- **New paid add-ons:** Content Kit from $99/mo, Report Builder $99/mo, Project Boost Pro $20/mo per project, Project Boost Max $200/mo per project. `[same]`
- The user-limits help article carries a **last-updated date of 3 September 2026**. `[https://help.ahrefs.com/en/articles/14333008-..., checked 4 Oct 2026]`

**Better than Semrush:** API access. Ahrefs ships API **and** MCP on its $129 Lite plan with 200,000 units/month, while Semrush gates the API to Advanced at $549. `[https://ahrefs.com/pricing, checked 4 Oct 2026; Semrush baseline per editor, unverified]`

**Worse than Semrush:** you cannot try it. Ahrefs' own pricing FAQ says "**We never run discounts**" and offers no free trial — the only free access is Ahrefs Free on a site you already own. Semrush has a free plan *and* a trial route. `[https://ahrefs.com/pricing FAQ "Do you offer discounts or free trials?", checked 4 Oct 2026]`
